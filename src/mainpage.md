# Welcome to Brick Game Documentation  

This project is a Tetris game implemented in C. Below you'll find detailed documentation about the codebase, its components, and usage instructions.  

## Features  
- Tetramino handling  
- Collision detection  
- Level and scoring system  

## Getting Started  
Hot keys:  
'Enter'       - start game  
'p'           - pause  
'Left arrow'  - move left  
'Right arrow' - move right  
'Down arrow'  - move down  
'Space'       - rotate  
'q'           - quit
